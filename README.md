# Library Management System

## Project Overview-
The Library Management System is a Python-based project developed to manage basic library operations using CSV file handling.

It provides a structured way to manage books, library members, book issuing and returning, fine calculations, recommendations, and library statistics.

## Tech that are used to make this
- Python
- CSV File Handling
- Git and GitHub

## Project Features
- **Book Management:** Add, display, search, update, and delete book records.
- **Member Management:** Register and search library members.
- **Issue and Return:** Manage book issuing and returning.
- **Fine Calculation:** Calculate fines for overdue books.
- **Book Recommendations:** Provide book recommendations and rankings.
- **Statistics and Reports:** Generate library-related statistics.

## Project Structure

- `main.py` – Main program
- `book_management.py` – Book management module
- `member_management.py` – Member management and issue/return module
- `fine.py` – Fine calculation module
- `recommendation.py` – Book recommendation and ranking module
- `report.py` – Statistics and reports module
- `books.csv` – Book records
- `users.csv` – Member records
- `records.csv` – Issue and return transaction records

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python main.py`
